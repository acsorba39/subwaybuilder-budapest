# Budapest for Subway Builder

A custom Budapest map for **Subway Builder**, packaged for installation through **Railyard**.

## Features

- Budapest and surrounding area
- Custom PMTiles basemap
- 3D buildings with variable heights
- Building, runway and taxiway collision
- Custom residential and job demand
- Budapest Airport demand points
- Native Railyard installation — no Docker, command line, or manual file patching required for players

## Demand data

The current demand model contains:

- **9,951** demand points
- **13,199** population units
- **2,639,800** represented people

The demand model combines residential population, employment destinations and airport demand.

## Installation

The recommended installation method is through **Railyard**.

Once the map is published in the Railyard Registry, install **Budapest** from Railyard and launch Subway Builder normally.
